## Overview

The **Meeting Transcript Intelligence Platform** is a decoupled 4-tier microservice architecture designed to ingest, process, index, and query multi-speaker meeting transcripts (e.g., from Fireflies.ai). It features dynamic chunking, semantic boundary detection, dual-level macro/micro vector retrieval, hybrid reranking, and LangGraph-driven synthesis.

## Data Flow

```
1. Transcript Ingestion:
   Fireflies Webhook / File Upload
      │
      ▼
   FS-backend (Ingestion Router)
      │
      ▼
   FS-AI-Engine (Normalizer -> Boundary Detector -> Signal Tagger -> Token Chunking -> Embedding Service)
      │
      ▼
   PostgreSQL / pgvector (Project -> Meeting -> MeetingTopic -> MeetingTurn)

2. Query Execution:
   User Query in Streamlit UI (FS-frontend)
      │
      ▼
   FS-backend (/api/v1/query)
      │
      ▼
   FS-AI-Engine Agent Router (Intent Classification)
      │
      ├──> Macro Retriever (High-level topic & meeting relevance)
      └──> Micro Retriever (Exact turn & statement similarity)
      │
      ▼
   Local Hybrid Reranker (Score Fusion)
      │
      ▼
   LangGraph Chat Engine / RAG Answerer (Synthesis with citations)
      │
      ▼
   Streamlit UI (Structured markdown response + citation cards)
```
